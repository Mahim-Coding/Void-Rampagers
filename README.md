# ⚔️ Void-Rampagers

A professional, mobile-responsive fan-made web portal and wiki hub for **Magic Rampage**. 

### Features:
- 🔥 Fire-themed splash screen & modern dark fantasy UI.
- ⚔️ Comprehensive Arsenal & Wiki database (Suits, Weapons, Potions, Skills).
- 🌍 Multi-language support (English, Bengali, Spanish, French, German, Arabic).
- ⚙️ Global customization (Theme toggling & Accent color picker).
- 📬 Automated contact system
